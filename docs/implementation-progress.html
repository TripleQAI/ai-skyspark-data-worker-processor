5. Five-minute point history Local contract gate passed, 28 September 2026 Certified historized IDs form exact half-open five-minute jobs (500 IDs/job pilot cap). The local reviewed reader requires provider-complete ID/window/row receipts, resolves wide-grid point columns, preserves source timestamp/time zone/status and typed values, and writes immutable raw S3 plus Timescale receipts. 6. Nightly equipment rules Local contract gate passed, 28 September 2026 The planner selects a complete source-local day and bounded prior-day overlap from reviewed binding values. The local reader requires complete equipment-ID/day/window receipts, including for zero detections; maps the supplied rule fields; and writes immutable raw and candidate S3 evidence through a pinned script. A provisional equipment/rule/day detection key and row revision hash distinguish corrections; duplicate keys within one query fail closed. Unit tests reject missing, truncated, mismatched and duplicate results. A synthetic 250-equipment run partitions 200/49/1 across two sites; control-store evidence shows one site advances while an incomplete partition blocks the other. All 37 pilot detections resolved to the sampled equipment in the Phase 0 assessment. Live SkySpark still needs a provider completeness receipt and stable detection-ID semantics; rules-to-TimescaleDB remains Phase 7.
7. Certified sinks and recovery Local sink and recovery gate passed, 28 September 2026 The six feed/target combinations write raw S3 plus certified S3 JSONL or TimescaleDB receipts. New metadata and rule revision/batch tables use bounded COPY staging and idempotent keys; metadata inventory publication can read Timescale evidence. A separate rules sink process exits after commit, then retry produces the same batch receipt; fenced certification advances the site checkpoint once. Replay needs a separately recorded active approval grant and atomically records audit, jobs, and backfill dispatch; a smaller backfill worker shares but caps project source permits. LocalStack EventBridge accepted certified publication IDs. Read-only storage measurement and retention preview are implemented. No object expiration or table aging is active until measured retention values and evidence lifetimes are approved.
